# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately rather than opening a public issue.

- **Preferred:** Use [GitHub's private vulnerability reporting](https://github.com/zkm/info/security/advisories/new) for this repository.
- **Alternative:** Email zachschneider@gmail.com with details.

Please include as much information as possible: the type of issue, steps to reproduce, and any relevant logs or proof-of-concept code.

## Response

This is a small, actively maintained personal project. Reports will be acknowledged as time allows, and a fix or mitigation will be prioritized based on severity.

## Supported Versions

Only the latest version on the `main` branch is supported. There are no maintained older releases.
